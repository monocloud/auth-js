    Interface IStorage

    Defines a storage adapter used to persist session data.

    Implement this interface to plug a custom storage backend (for example, an encrypted store, secure cookie helper, or a wrapper around IndexedDB) into MonoCloudWebJSClient.

    Built-in implementations:

    • LocalStorage (default) - backed by window.localStorage.
    • SessionStorage - backed by window.sessionStorage.
    • MemoryStorage - in-memory store, useful for testing.
    interface IStorage {
        getItem(key: string): Promise<string | null>;
        removeItem(key: string): Promise<void>;
        setItem(key: string, value: string): Promise<void>;
    }
