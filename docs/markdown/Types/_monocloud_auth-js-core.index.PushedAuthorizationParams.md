# Type: PushedAuthorizationParams

Parameters used when creating a Pushed Authorization Request (PAR).

This type mirrors [AuthorizationParams](/sdks/js-core/api-reference/types/authorizationparams) but excludes `requestUri`,
since the `request_uri` value is generated by the authorization server
after a successful PAR request and must not be supplied by the client.

## Extends

- `Omit`\<[`AuthorizationParams`](/sdks/js-core/api-reference/types/authorizationparams), `"requestUri"`\>
