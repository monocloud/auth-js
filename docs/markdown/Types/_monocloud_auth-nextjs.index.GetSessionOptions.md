# Type: GetSessionOptions

Options used to control session retrieval behavior when calling `getSession()`.

## Properties

| Property                                        | Type      | Description                                                                                             |
| ----------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------- |
| `refetchUserInfo?` | `boolean` | When enabled, re-fetches user information from the `UserInfo` endpoint and updates the current session. |
